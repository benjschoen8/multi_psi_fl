\title{PSI--FL Relation Table\\\large Abstract protocols and a keyword-attention instantiation}

\maketitle
\noindent Relation-table construction runs once before federated learning.
We first specify five abstract algorithms: exact PSI, description-based
relation construction, fuzzy PSI, affinity-based relation construction, and
an image filter. We then instantiate the semantic representation with keyword
attention and describe the implemented precision-first extension.
The first five algorithms deliberately leave encoders, affinity functions,
and cryptographic mechanisms unspecified.

\paragraph{Notation.}
Client $i$ holds local classes $C_i$ and a private map $\pi_i$ from local ids
to masked ids. An external class handle is $(i,\pi_i(a))$; raw local ids and
private class samples stay local. A relation is a pair of these handles,
optionally with a matching weight. $\operatorname{Mutual}(R)$ selects positive,
unique maxima in both their row and column; zero scores and ties abstain.
All candidate matrices below use masked-id order.

\paragraph{Abstraction boundary.}
Exact PSI tests equality of canonical description tokens. Fuzzy PSI tests a
public similarity predicate. Neither primitive alone establishes that two
classes have the same semantic identity. Algorithms~\ref{alg:a1} and
\ref{alg:a2} specify a conceptual exact-PSI baseline, not an existing
\texttt{run\_rt\_protocol} branch. The remaining abstractions organize the
fuzzy and image-filtering behavior used by the implementation.
An ideal primitive's stated output is not a claim that the current CKKS
prototype achieves that primitive's ideal leakage guarantee.

\section*{I. Abstract protocols}
\begin{algorithm}[H]
\caption{Simple exact PSI (abstract primitive)}\label{alg:a1}
\small\begin{algorithmic}[1]
\Require client $i$'s private set $S_i$; client $j$'s private set $S_j$
\Ensure common tokens $I$ to the designated participants
\Procedure{ExactPSI}{$S_i,S_j$}
 \State jointly evaluate set equality through an exact-PSI primitive
 \State $I\gets S_i\cap S_j$
 \State \Return $I$
\EndProcedure
\end{algorithmic}
\smallskip\noindent\small
This is a functionality specification: neither party sends its plaintext set
to the other. A selected implementation must define its security model and
leakage (for example set sizes and the intersection).
\end{algorithm}

\begin{algorithm}[H]
\caption{Description-based relation construction using exact PSI}\label{alg:a2}
\small\begin{algorithmic}[1]
\Require local classes $C_i$, descriptions $d_i[a]$, agreed canonicalization $\operatorname{Canon}$
\Ensure masked-id relations $E$
\For{each client $i$}
 \State $u_i[a]\gets\operatorname{Canon}(d_i[a])$ for every $a\in C_i$
 \State retain $(a,\pi_i(a),u_i[a])$ in a private local table
\EndFor
\State $E\gets\emptyset$
\For{each pair $i<j$}
 \State $I\gets\psiexact(\{u_i[a]\}_a,\{u_j[b]\}_b)$ \Comment{Algorithm 1}
 \For{each $u\in I$}
  \State exchange masked handles associated with $u$
  \If{$u$ identifies exactly one class $a$ at $i$ and one class $b$ at $j$}
   \State add $(i,\pi_i(a),j,\pi_j(b),1)$ to $E$
  \EndIf
 \EndFor
\EndFor
\State \Return $E$ for global relation-table construction
\end{algorithmic}
\smallskip\noindent\small
Equality is on the \emph{whole canonical description}, not merely one shared
keyword. A common vocabulary alone does not ensure identical descriptions.
Synonyms and different languages require a shared canonicalization or the
fuzzy extension below. Ambiguous duplicate descriptions are left unresolved.
Releasing matched masked handles is an extra relation-disclosure step beyond
plain set intersection.
\end{algorithm}

\begin{algorithm}[H]
\caption{Labeled fuzzy PSI with a threshold ladder (abstract primitive)}\label{alg:fpsabstract}
\small\begin{algorithmic}[1]
\Require private labeled objects $\{x_a\}_a$, $\{y_b\}_b$; public similarity $\operatorname{sim}$
\Require public thresholds $\Delta$ and allowed-pair mask $M$
\Ensure pairwise ranks $R$ indexed by masked handles
\Procedure{FPSIRank}{$\{x_a\},\{y_b\},\operatorname{sim},\Delta,M$}
 \State jointly evaluate the following functionality without exchanging raw objects:
 \For{each pair $(a,b)$}
  \State $R[a,b]\gets M[a,b]\sum_{\delta\in\Delta}\ind\{\operatorname{sim}(x_a,y_b)>\delta\}$
 \EndFor
 \State \Return $R$ to the designated participants
\EndProcedure
\end{algorithmic}
\smallskip\noindent\small
A positive rank nominates a similar pair; more crossed thresholds indicate
stronger evidence. The strict inequality defines a similarity threshold,
not a distance tolerance. This labeled variant exposes pair identities and
quantized similarity ranks; it is more informative than an unlabeled fuzzy
intersection. The abstract loop specifies an output, not plaintext evaluation
by a trusted server. Cryptographic realization is deferred to Part II.
\end{algorithm}

\begin{algorithm}[H]
\caption{Affinity-based relation construction using fuzzy PSI}\label{alg:a3}
\small\begin{algorithmic}[1]
\Require local class objects $x_i[a]$; public ordered references $P=(p_1,\ldots,p_m)$
\Require affinity $\aff(x,y)$, profile transform $\mathcal N$, profile similarity $\operatorname{sim}$, $\Delta$
\Ensure weighted masked-id relations $E$ and optional rank matrices
\For{each client $i$ and each $a\in C_i$}
 \State $s_i[a]\gets\mathcal N([\aff(x_i[a],p_1),\ldots,\aff(x_i[a],p_m)])$
\EndFor
\State $E\gets\emptyset$
\For{each client pair $i<j$}
 \State $R_{ij}\gets\fprank(s_i,s_j,\operatorname{sim},\Delta,\mathbf 1)$ \Comment{Algorithm 3}
 \For{each $(a,b)\in\mutual(R_{ij})$}
  \State add $(i,\pi_i(a),j,\pi_j(b),R_{ij}[a,b])$ to $E$
 \EndFor
\EndFor
\State \Return $E$ and $\{R_{ij}\}$
\end{algorithmic}
\smallskip\noindent\small
$\aff(x,y)$ expresses a class object's affinity to a public reference.
Fuzzy PSI compares the resulting \emph{profiles} through $\operatorname{sim}$;
these are distinct operations. No concrete encoder, cosine formula, or
classifier is assumed here. The reference order and profile coordinates must
be compatible across clients. Image-based profiles instantiate
\texttt{affscan}; text attention provides another shared-reference construction.
\end{algorithm}

\begin{algorithm}[H]
\caption{Image filter for candidate relations (abstract cascade)}\label{alg:a4}
\small\begin{algorithmic}[1]
\Require candidate pairs $E'_{ij}$ from a preceding description/semantic stage
\Require local image-class objects $X_i^a$, public image references $P_I$
\Require image affinity $\aff_I$, transform $\mathcal N_I$, similarity $\operatorname{sim}_I$, $\Delta_I$
\Ensure surviving candidate pairs $E_{ij}$ and image ranks $R_I$
\For{each client $i$ and class $a$}
 \State $s_i^I[a]\gets\mathcal N_I([\aff_I(X_i^a,p)]_{p\in P_I})$
\EndFor
\For{each client pair $i<j$}
 \State $A\gets\{a:(a,b)\in E'_{ij}\}$; $B\gets\{b:(a,b)\in E'_{ij}\}$
 \State $M[a,b]\gets\ind\{a\in A\text{ and }b\in B\}$
 \State $R_I\gets\fprank(s_i^I,s_j^I,\operatorname{sim}_I,\Delta_I,M)$ \Comment{Algorithm 3}
 \State $E_{ij}\gets E'_{ij}\cap\mutual(R_I)$
\EndFor
\State \Return $\{E_{ij},R_I\}_{i<j}$
\end{algorithmic}
\smallskip\noindent\small
This is an intersection filter: image evidence can remove candidates but
cannot recover a pair discarded by the preceding stage. The mask covers the
Cartesian product of candidate endpoint sets, so image rivals are compared
within those sets. The preceding stage may be Algorithm~\ref{alg:a2},
Algorithm~\ref{alg:a3}, or keyword attention. In code,
\texttt{filter} uses direct-description fuzzy ranks before this filter;
\texttt{attn\_filter/intersection} uses attention-derived fuzzy ranks instead.
\end{algorithm}

\paragraph{Assembling the global table (abstract).}
Collect weighted masked relations, process stronger edges first, and merge
compatible components. Never put two classes of the same client in one
component. Assign each component a global id and retain unmatched classes as
singletons. For precision-first matching, also require support for every
cross-component pair, as detailed after Algorithm~\ref{alg:precision}.
Subsequent FL rounds query each client by its masked handle; the client
resolves the local id privately.

\paragraph{Reading order.}
Algorithms 1--2 establish exact equality and its relation-table use.
Algorithm 3 replaces equality with a similarity predicate; Algorithm 4 supplies
affinity profiles to it. Algorithm 5 adds visual corroboration.
The following section makes the semantic and visual representations concrete,
while retaining Algorithm 3 as the abstract fuzzy-PSI interface.

\section*{II. Implemented keyword attention and precision-first matching}
\paragraph{Keyword-level input.}
A description is a list of concepts, such as \texttt{[digit, zero]}.
Each keyword is encoded separately; the list is never joined into a sentence
before encoding. All clients share the same ordered public text-anchor list
$A$, while each client embeds it using its own text encoder $E_i$.
The current implementation uses one head and no learned query/key projection.
Local inverse document frequency (IDF), rather than a learned keyword gate,
downweights words repeated across local classes.

\paragraph{Conventions for the concrete algorithms.}
$\unit$ normalizes each row with denominator
$\max(\|v\|_2,10^{-12})$.
$\fprank(U,V,\Delta,M)$ abbreviates Algorithm 3 with
$\operatorname{sim}(u,v)=u^\top v$ on normalized coordinates.
$\mutual$ retains positive unique row-and-column maxima.
\begin{algorithm}[H]
\caption{Keyword-attention representation and standalone matching}
\label{alg:a3b}
\footnotesize\begin{algorithmic}[1]
\Require ordered public text anchors $A$, client-local text encoder $E_i$, keyword lists $D_i[a]$, $\tau>0$
\Ensure text coordinates $z_i[a]$ indexed by the public anchor list
\For{each client $i$}
 \State $K_i\gets\unit([E_i(w)]_{w\in A})$; $n\gets|C_i|$
 \State $K_{c,i}\gets K_i-\operatorname{columnmean}(K_i)$
 \State compute compact SVD $K_{c,i}=U\Sigma V^\top$
 \State retain singular values $\sigma>\max(10^{-6}\sigma_{\max},10^{-12})$
 \State $W_i\gets U_{\rm keep}\Sigma_{\rm keep}^{-1}U_{\rm keep}^\top$
 \State $\mathrm{df}_i(w)\gets|\{a\in C_i:w\in D_i[a]\}|$
 \For{each class $a\in C_i$}
  \State encode every keyword separately: $q_k\gets\unit(E_i(D_i[a]_k))$
  \State $c_a(w)\gets$ multiplicity of keyword $w$ in $D_i[a]$
  \State $\widetilde w_k\gets\log(n/\mathrm{df}_i(D_i[a]_k))/c_a(D_i[a]_k)$
  \If{all $\widetilde w_k=0$}
   \State $\widetilde w_k\gets1/c_a(D_i[a]_k)$ for every keyword
  \EndIf
  \State $w_k\gets\widetilde w_k/\sum_\ell\widetilde w_\ell$
  \State $\alpha_k\gets\operatorname{softmax}(q_kK_i^\top/\tau)$ for each keyword
  \State $\bar\alpha_i[a]\gets\sum_k w_k\alpha_k$
  \State $\ell_i[a]\gets\log(\max(\bar\alpha_i[a],\varepsilon_{\rm tiny}))$ elementwise
  \State $z_i[a]\gets\unit((\ell_i[a]-\operatorname{mean}(\ell_i[a]))W_i)$
 \EndFor
\EndFor
\Statex \textbf{Standalone \texttt{attn} matching.}
\For{each pair $i<j$}
 \State $R_T\gets\fprank(z_i,z_j,\Delta_T,\mathbf{1})$
 \State $R_T[a,b]\gets0$ wherever $R_T[a,b]<|\Delta_T|$
 \State emit masked relations from $\mutual(R_T)$, weighted by $R_T[a,b]$
\EndFor
\Statex \hrulefill
\Statex \raggedright\textbf{IMPLEMENTATION.} \texttt{keyword\_attn} and
\texttt{anchor\_log\_coordinates}, default \texttt{coord="log\_whiten"}, one head.
With legacy \texttt{desc\_vecs}, a whole description is one query and receives
weight 1; without keyword metadata, weights are uniform. No projection head or
keyword weights are trained. Different text encoders embed the same anchor
\emph{list}; identical numerical keys are not required. This shared indexing
does not guarantee semantic alignment of arbitrary encoders. With one active
keyword, the corrected coordinate is an anchor-span projection.
\end{algorithmic}\end{algorithm}

\subsection*{Concrete visual signals and fuzzy-PSI realization}
\label{alg:affimpl}
Let $F$ be the common frozen image encoder and $P_I$ the ordered public,
unlabeled image probes. Define
\[
 \mu=|P_I|^{-1}\sum_{p\in P_I}F(p),\qquad
 r_i(a)=|X_i^a|^{-1}\sum_{x\in X_i^a}F(x)-\mu,\qquad h_p=F(p)-\mu.
\]
The concrete instantiation of the abstract image affinity is
\[
 \aff_I(X_i^a,p)=\unit(r_i(a))^\top\unit(h_p).
\]
\[
 s_i[a]=\unit\left([\aff_I(X_i^a,p)]_p-\operatorname{mean}_p\aff_I(X_i^a,p)\right).
\]
Thus profile matching compares $s_i[a]^\top s_j[b]$.
Precision-first adds full-feature vectors $v_i[a]=\unit(r_i(a))$ and
compares $v_i[a]^\top v_j[b]$ as a separate verification signal.
These visual signals share the same encoder and samples, so they are not
statistically independent evidence.

\paragraph{Data use.}
The MNIST harness uses a shared pretrained ResNet-18 with its classifier head
removed. Legacy summaries use at most 64 samples/class; precision mode uses
\texttt{precision\_summ} from all available samples, falling back to
\texttt{summ} if unavailable. Server setting
\texttt{rt\_exemplars\_per\_class=0} selects all samples.
Eligible classes must meet the configured sample minimum; ineligible classes
remain singleton ids. No cross-client ground-truth labels decide matches.

\paragraph{Fuzzy PSI realization.}\label{alg:fpsimpl}
For Algorithm 3, the CKKS receiver encrypts its coordinate vectors; the sender
homomorphically computes dot products and returns encrypted values
$(u^\top v-\delta)rM[a,b]$, with independent positive
$r\sim\operatorname{Uniform}(1,1000)$. The receiver decrypts, applies the strict
positive test (and mask), sums threshold bits, and returns ranks.
This prototype reveals masked magnitudes to the receiver as well as ranks
and relevant sizes/masks; it is not a proven realization of a bits-only ideal
functionality. Approximation can alter bits near thresholds.
\texttt{psi="plain"} is a non-private reference evaluation.

\paragraph{Rank bounds for verification.}
For sorted thresholds $d_1\le\cdots\le d_m$, set $d_0=-1$ and $d_{m+1}=1$.
For rank $r$, $\bounds(r,\Delta)=(d_r,d_{r+1})$ gives conservative lower
and upper bounds for evaluated, unmasked pairs with exact threshold bits.
Mask-forced zeros give no similarity bound. CKKS numerical errors mean these
are not unconditional certificates in encrypted execution.
The experimental ladders are
\[
 \Delta_T=\{.90,.85,\ldots,.40\},\quad
 \Delta_A=\{.990,.985,\ldots,.950\},
\]
\[
 \Delta_V=\{.50,.55,\ldots,.85\}\cup\{.900,.902,\ldots,.998\}.
\]
These are configurable settings, not guarantees of semantic correctness.

\begin{algorithm}[H]
\caption{Precision-first attention--affinity preprocessing: current \texttt{psi\_attn\_filter}}
\label{alg:precision}
\footnotesize\begin{algorithmic}[1]
\Require $z_i$ from Algorithm~\ref{alg:a3b}, $(s_i,v_i)$ from the concrete visual construction
\Require ladders $\Delta_T,\Delta_A,\Delta_V$; verification floor $\eta=.90$, margin $\gamma=.01$
\Ensure weighted edges $E$, supported pair set $H$, uncertain candidates for local review
\State $E,H\gets\emptyset$
\For{each client pair $i<j$}
 \State $R_T\gets\fprank(z_i,z_j,\Delta_T,\mathbf{1})$
 \State $M[a,b]\gets\ind\{R_T[a,b]>0\}$
 \State $R_A\gets\fprank(s_i,s_j,\Delta_A,M)$ \Comment{zero if no allowed pairs}
 \State $R_V\gets\fprank(v_i,v_j,\Delta_V,\mathbf{1})$ \Comment{all competitors, unmasked}
 \State $(L_T,U_T)\gets\bounds(R_T,\Delta_T)$
 \State $(L_A,U_A)\gets\bounds(R_A,\Delta_A)$; $(L_V,U_V)\gets\bounds(R_V,\Delta_V)$
 \State $B\gets0$; $G\gets0$
 \For{each pair $(a,b)$}
  \State $T\gets[L_T[a,b]\ge\max\Delta_T]$; $I\gets[L_A[a,b]\ge\max\Delta_A]$
  \If{$R_T[a,b]=0$ or $R_A[a,b]=0$ or $\neg(T\lor I)$ or $L_V[a,b]<\eta$}
   \State \textbf{continue}
  \EndIf
  \State $q\gets\max(\{U_V[a,b']:b'\ne b\}\cup\{U_V[a',b]:a'\ne a\}\cup\{-1\})$
  \If{$(T\land L_V[a,b]\ge q-\gamma)$ or $(\neg T\land L_V[a,b]\ge q+\gamma)$}
   \State $B[a,b]\gets1$; $G[a,b]\gets(L_T[a,b]+L_A[a,b]+L_V[a,b])/3$
   \State add the masked unordered pair $\{(i,\pi_i(a)),(j,\pi_j(b))\}$ to $H$
  \EndIf
 \EndFor
 \State add $(i,\pi_i(a),j,\pi_j(b),G[a,b])$ to $E$ for $(a,b)\in\mutual(G)$
 \State record strongly nominated pairs failing verification as uncertain, not as confirmed errors
\EndFor
\State \Return $(E,H)$ for the consistent global grouping described below; retain review records locally
\Statex \hrulefill
\Statex \raggedright\textbf{IMPLEMENTATION.} \texttt{attn\_match="precision"},
\texttt{verified\_candidates}, and \texttt{rank\_bounds}. Confidence and margins
use only threshold ranks. $R_V$ must include every image-feature rival: hiding
rivals before checking the margin could create artificial confidence.
Strong text may resolve visually close alternatives within $\gamma$;
weak-text image rescue instead requires a margin of $\gamma$ over all rivals.
The image-feature floor applies in both cases.

\end{algorithmic}\end{algorithm}

\subsection*{What precision-first changes (and what it preserves)}
\noindent Both standalone \texttt{attn} and precision-first
\texttt{attn\_filter} use Algorithm~\ref{alg:a3b}'s keyword queries, local IDF
weights, public text anchors, and corrected log-attention coordinates.
Precision-first is a \emph{matching and verification policy}; it does not
train a stronger attention encoder.

\toprule
Aspect & Original standalone \texttt{attn} & Precision-first \texttt{attn\_filter}\\\midrule
Semantic signal & Keyword-attention coordinates & Same keyword-attention coordinates\\

Visual evidence & None & Image profiles plus full-feature verification\\
Rival comparison & Unique mutual maximum of text ranks & Full-feature bounds against all row/column rivals, then mutual fused score\\
Local summaries & No images used & All available samples when supplied\\

Uncertainty & Unmatched classes remain separate & Also records verification and grouping conflicts for review\\
\bottomrule
\end{tabular}
\end{center}

\paragraph{The two earlier filtered variants.}
The legacy \texttt{intersection} variant runs text mutual matching first and
then Algorithm~\ref{alg:a4}; it can only discard earlier candidates.
The \texttt{fusion} variant retains positive text/profile ranks, requires at
least one highest-rung rank, and performs mutual matching on
$R_T|\Delta_A|+R_A|\Delta_T|$.
Neither has the extra full-feature verification or complete-link requirement.
Precision-first can rescue a weak but positive text match using strong image
profile evidence, provided the full-feature verification beats every rival
by the required margin. It cannot rescue a zero-text-rank pair.

\paragraph{Strong-text versus image-led verification.}
Every accepted pair must satisfy $L_V\ge.90$ by default.
Let $q$ be the largest full-feature upper bound among every alternative in
the pair's row and column. Strong-text candidates require
$L_V\ge q-.01$: text may resolve a visually close ambiguity.
Weak-text, strong-profile candidates instead require $L_V\ge q+.01$.
Thus the strong-text case permits a tolerance; it does not demand a strict
visual winning margin. Ranking then averages text, profile, and verification
lower bounds, using only fuzzy-PSI outputs.

\paragraph{Consistent global grouping.}\label{alg:gid}
Sort selected edges by score. Merge two components only if they have no
client in common and every cross-component pair belongs to the supported set
$H$ from Algorithm~\ref{alg:precision}. A transitive path alone is insufficient.
Rejected merges are recorded; remaining singletons retain their own global ids.
Enforcing this rule discloses supported masked-pair relations $H$ to the
aggregator in addition to selected edges.

\paragraph{Accuracy objective and cost.}
The goal is fewer false merges, accepting extra offline computation,
communication, and potentially lower recall. All-sample summaries, a finer
verification ladder, and all-rival comparisons increase cost. Sparse or
ambiguous data may still prevent correct mappings, and no perfect-mapping
guarantee follows from these checks. The centrally orchestrated experiment
simulates client roles; a deployment must implement their communication and
account for the stated leakage. The training adapter \texttt{to\_group\_map}
uses a known shared party/local-label schema and adds no new semantic evidence.
